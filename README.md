# 📝 Contador de Caracteres e Palavras

Uma **ferramenta web interativa** para contagem de **caracteres, palavras, linhas** e **tempo estimado de leitura**, com atualização em **tempo real**.

Ideal para **escritores, estudantes, programadores e criadores de conteúdo** que precisam analisar textos de forma rápida, prática e confiável.

Projeto desenvolvido com **HTML, CSS e JavaScript puro**, com foco em **usabilidade**, **experiência do usuário (UX)** e **persistência de dados**.

## 🔍 Como Funciona

1️⃣ O usuário digita ou cola um texto no campo principal  
2️⃣ A contagem de:
- caracteres  
- palavras  
- linhas  
- tempo de leitura  

é atualizada automaticamente em tempo real ⚡  

3️⃣ O texto é salvo automaticamente no navegador a cada alteração  

🔄 Ao recarregar a página:
- o texto é restaurado automaticamente  
- a data e horário da última edição são exibidos  

🧭 O usuário pode:
- copiar o texto  
- limpar todo o conteúdo  
- alternar entre modo claro e escuro

## 💾 Persistência de Dados

Utiliza **`localStorage`** para armazenar:

📦 Texto digitado  
🕒 Horário da última edição  

Isso garante que **nenhum conteúdo seja perdido** ao atualizar ou fechar a página.
